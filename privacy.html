Project privacy policy

How this project handles data.

Last updated: 15 October 2026

This policy applies to Personal Search Analytics, a personal desktop reporting project maintained by GitHub user hxh98ster. It covers the connector's use of Google data and this public documentation website.

Google information accessed

After the operator grants permission, the connector can read data from Google Search Console and Google Analytics properties that the operator is authorized to access. This includes property identifiers and names; Search Console queries, page URLs, clicks, impressions, click-through rates, positions, countries and devices; sitemap and URL inspection information; and aggregate Google Analytics reports such as traffic sources, events and website usage metrics.

The connector requests only https://www.googleapis.com/auth/webmasters.readonly and https://www.googleapis.com/auth/analytics.readonly. It does not request access to Gmail, contacts, Drive files or a Google account password. Google handles sign-in and consent.

Purpose and use

Google data is used to answer the operator's analytics questions, review search and website performance, and prepare requested reports. The connector does not sell Google data or use it to target advertising. It does not provide a public database of connected properties or reports.

Storage and retention

OAuth credentials and refresh tokens are stored in credential files on the operator's computer. They are not part of this public website or repository and are not included in normal report responses. Local file protection depends on the computer's operating-system and access controls.

The operator may save reports or exports locally. Local credentials and saved reports remain until the operator deletes them; this project does not promise automatic deletion after a fixed period. Revoking Google access stops future authorized requests but does not delete reports already saved.

Codex and other service providers

Connector results can be returned to the operator's Codex conversation for AI-assisted analysis. Those results are then processed by OpenAI as part of providing Codex. Conversation retention and other processing depend on the operator's OpenAI service plan, account settings and applicable policies. Processing is therefore not limited to the local computer.

Google processes authorization and API requests. GitHub Pages hosts this documentation site and may process technical request information, such as IP addresses and request logs, under GitHub's privacy policy. The site itself contains no analytics script, advertising script, Google sign-in form or report-upload form. Viewing this site does not connect a Google account.

Revocation and deletion

The operator can revoke the project's access in Google Account third-party connections. To remove retained information, the operator must also delete local credential files and report exports, and manage relevant Codex conversations through their OpenAI account. These actions do not delete the original data held in Google Search Console or Google Analytics.

Contact and changes

For private questions about Google data or deletion, contact the support email displayed on this project's Google consent screen. General non-sensitive questions may be posted in the project issue tracker. Do not post tokens, credentials, private reports or personal information there.

If the connector's data practices change, this policy will be updated and its revision date changed. The public repository records revisions to these documentation pages.
