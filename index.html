A personal desktop analytics project

Your search and website reports, in one local workflow.

Personal Search Analytics connects an authorized operator's Google Search Console and Google Analytics accounts to a local reporting workflow. It helps the operator review search visibility, indexing information and website performance.

What it does

The connector reads Search Console properties, search performance reports, sitemaps and URL inspection results. It also reads Google Analytics account and property information and aggregate analytics reports. Results can be reviewed with Codex for analysis and reporting.

Access is read-only

Google access is requested through OAuth, with the webmasters.readonly and analytics.readonly permissions. These permissions do not allow the connector to edit a website, change Analytics settings or manage a Google account. The operator chooses which accessible properties to query.

Who this is for

This is a personal-use project maintained by hxh98ster. It is not a public analytics service and does not offer account registration. The connector runs on the operator's computer; this website provides public project information and its privacy policy.

Data and support

Read the privacy policy for details about Google data, local storage, Codex processing and revoking access. For general project questions, use the project issue tracker. Never post credentials, private reports or personal information in a public issue. Private data requests can be sent to the support email displayed on the Google consent screen.
